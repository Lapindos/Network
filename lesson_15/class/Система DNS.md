# Система доменных имён DNS

## Имя вместо адреса

Узлы в сети находят друг друга по IP-адресам. Имена вроде `vk.com` нужны людям: их проще запомнить. **DNS** переводит имя в адрес. До DNS соответствия вели в общем файле вручную. С ростом сети файл перестал помещаться в одну точку, и справочник сделали распределённым.

DNS — и база на серверах, и протокол запросов. Протокол относится к прикладному уровню. Клиент есть в обычных операционных системах. В браузер можно вписать и сам IP, страница откроется без имени.

## Как идёт запрос

Компьютер спрашивает резолвер, обычно сервер провайдера или локальный кэш. Если ответа в кэше нет, вопрос поднимается по иерархии: корневые серверы знают, где зоны верхнего уровня, те знают серверы конкретного домена, а авторитативный сервер домена отдаёт запись. Полученный адрес резолвер запоминает на время TTL, чтобы не повторять путь.

Корневых имён серверов тринадцать, у каждого много копий по миру.

## Из чего состоит имя

Имя читают справа налево.

- Домен верхнего уровня — зона: национальная (`.ru`) или общая (`.com`). Некоторые национальные зоны регистрируют только местным организациям.
- Домен второго уровня — само имя сайта. Пара «имя + зона» уникальна.
- Домен третьего уровня — поддомен, он опирается на домен второго уровня.

## Записи

Связи лежат в записях зоны. Для сайта важна запись адреса. Запись **SOA** описывает саму зону: главный сервер имён, почту администратора и таймеры. Она не выбирает IP страницы, но без неё зону не передают между серверами.

Зоны ведут разные организации. Это и есть распределённое администрирование: никто не хранит весь Интернет в одном файле.
