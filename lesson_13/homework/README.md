# Домашнее задание 12.10

Урок 13. В Cisco Packet Tracer внутренняя сеть выходит через два маршрутизатора к серверам. В браузере открыт адрес `http://213.234.10.2`, на странице — приветствие NetSkill.

Такой адрес и замена стандартной страницы Packet Tracer на NetSkill есть в практической настройке NAT: внешний узел открывает сервис по публичному адресу, а маршрутизатор переводит обращение внутрь.
