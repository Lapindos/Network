# Домашнее задание 14.09

Урок 2. Нужно взять пять примеров и для каждого показать объект или систему и типичную ошибку на одном из уровней модели OSI.

## Решение

## Пример 1: Прикладной уровень (Application Layer, 7)

**Объект/система:** веб-браузер (Google Chrome, Firefox).

**Обоснование:** прикладной уровень — это набор приложений, полезных пользователям: гипертекстовые web-страницы, электронная почта, доступ к разделяемым файлам. Браузер использует HTTP/HTTPS, чтобы запросить и получить страницу. Это конечное приложение, с которым работает пользователь.

**Ошибка:** HTTP 404 Not Found — запрошенный ресурс на сервере не найден.

## Пример 2: Уровень представления (Presentation Layer, 6)

**Объект/система:** протокол TLS/SSL.

**Обоснование:** уровень представления согласует синтаксис и семантику данных, а также шифрует и расшифровывает их. TLS и более ранний SSL как раз занимаются защитой данных между клиентом и сервером.

**Ошибка:** ошибка сертификата SSL, например `ERR_CERT_DATE_INVALID`: срок сертификата истёк, защищённое соединение не устанавливается.

## Пример 3: Транспортный уровень (Transport Layer, 4)

**Объект/система:** протокол TCP.

**Обоснование:** транспортный уровень передаёт данные между процессами, следит за надёжностью и доводит сообщение от источника до адресата. TCP даёт канал с сохранением порядка и повторной передачей потерянного.

**Ошибка:** потеря сегмента TCP. Если подтверждение не пришло вовремя, отправитель посылает сегмент снова. При постоянных потерях соединение может оборваться по таймауту.

## Пример 4: Сетевой уровень (Network Layer, 3)

**Объект/система:** маршрутизатор и протокол IP.

**Обоснование:** сетевой уровень объединяет сети разных технологий. Он задаёт глобальные адреса и выбирает маршрут пакета.

**Ошибка:** `Destination Host Unreachable` (ICMP) — маршрутизатор не знает, как доставить пакет адресату.

## Пример 5: Канальный уровень (Data Link Layer, 2)

**Объект/система:** коммутатор и Ethernet.

**Обоснование:** канальный уровень передаёт кадры по каналу, находит их границы, обнаруживает ошибки и пользуется MAC-адресами. Коммутатор пересылает кадры по этим адресам.

**Ошибка:** коллизия в Ethernet — два устройства одновременно передают в общую среду, кадры портятся. В разделяемой среде это замечает CSMA/CD.
